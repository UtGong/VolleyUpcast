# Local inference assets

These assets are redistributed for on-device processing. No user media is sent to these projects or to a model service. Source URLs and integrity digests are recorded in `models/manifest.json`.

- **Google MediaPipe Tasks Vision 1.2.0** and **BlazePose GHUM Full float16 v1**: Apache License 2.0. Copyright Google LLC. Full license: `vendor/mediapipe/LICENSE` and `models/pose/LICENSE`. [Official model card](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20BlazePose%20GHUM%203D.pdf). Selected module-worker CPU/WASM files are unmodified. The model estimates a single body; distant, occluded people and metric depth are outside reliable assumptions.
- **Hugging Face Transformers.js 4.3.2**: Apache License 2.0. Copyright Hugging Face. Full package license: `vendor/transformers/LICENSE`. Modification: the web bundle's two bare ONNX imports (`onnxruntime-web/webgpu` and `onnxruntime-common`) point to the same self-hosted CPU WASM bundle. Unused Mistral3 conditional-generation exports and its registry entry are omitted from this speech-only distribution: its upstream class identifier triggered a GitHub secret-scanning false positive. No secret-scanning bypass was used. No remote model fallback is enabled.
- **Microsoft ONNX Runtime Web 1.31.0-dev.20260914-8d85527a0**: MIT License, copyright Microsoft Corporation. Full license: `vendor/ort/LICENSE`. Only the CPU WASM bundle, module and SIMD WASM are included, unmodified. One thread avoids cross-origin isolation requirements on GitHub Pages.
- **Xenova/whisper-tiny.en**, pinned conversion revision `79fb389fc764e7c395bd330e9531d9d32ada7049`: repository conversion metadata lists Apache 2.0 (`models/whisper-tiny.en/LICENSE-CONVERSION`); upstream OpenAI Whisper is MIT (`LICENSE-UPSTREAM` in the same folder). Quantized encoder and merged decoder plus tokenizer/configuration files are unmodified. English-only short-note transcription is fallible, especially silence, background noise and volleyball terms.

Full package archives were obtained from the official npm registry; the pose task is from Google's official model storage and the speech conversion from the pinned Hugging Face repository. npm SHA-512 integrity, model hashes and transferred sizes were checked before use. No package lifecycle scripts were run. The root prototype remains unlicensed; these notices do not change third-party licenses.
